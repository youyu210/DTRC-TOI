# 实现、验证结果与限制

本版本源自 `pcg-dual-graph-v1-validated`（145c87e），实现冻结为 `efba65e937e9c37e81b7848cd8984fdceb85784b` / `residual-toi-graph-v1`。二进制 SHA-256 为 `144aa9c868be179d0b02274e8435cff5a332846fe5870ecb9c1db6283753fbce`。后续只修订实验控制与分析脚本、文档，不修改该二进制或生产 C++/CUDA 实现。

## 实现核验

原始 PCG 函数文本、PCG 双段图、ABD 物理、预条件器、ACCD、BVH、输入资产和 CMake 与保留版本一致。新增内容限于外层附加退出、真实梯度范数归约和诊断入口。

真实残差使用原统一求解器坐标中的 infinity norm；固定 ABD 梯度由原组装器置零，固定 FEM 分量被排除。保留原缩放，不将原始反力、PCG 线性残差或方向范数用作新残差。短测和独立默认 Kmin 轨迹中，实际组装 RHS 的主机 infinity norm 与 GPU 归约完全一致。

累计索引为：第 5 次接受更新后的真实梯度初始化固定参考，第 6 次更新才开始累计；通过原 CCD、相交回溯、能量回溯后保存最终 alpha，下一轮正常梯度/Hessian 组装取得新状态残差并验收。补偿系数为 1，预算不裁剪，异常样本禁止附加退出。原方向停止规则仍优先保留，附加退出同时要求原边界动画完成条件。

纯 TOI 和当前残差门控也延后到同一组装位置验收，保证最后一次梯度/Hessian 成本一致。它们与接受步后立即退出的实现，在最后一次组装开销上存在差别。

## 实际实验

- Release 构建成功。
- 实际 C++ 标量测试覆盖理想残差序列退化、完整步长反例、历史超额、残差反弹、固定参考、零残差/floor 和异常输入。
- 最终二进制短测：场景 1、3、5，各 original/toi/compensated/gated 两帧，Kmin=1 用于实际触发分支；逐轮公式、上界、参考初始化和原始 RHS 核验通过。
- 主实验：3 场景 × 3 版本 × 3 次 × 100 帧 = 2700 帧；Kmin=6、epsilon=1e-3，顺序循环轮换，GPU 0，串行运行，同一二进制和资产。
- 完整统一参考：三个场景各 100 帧，原停止规则，Newton 与 PCG 容差各乘 0.5。
- 消融：每场景 gated/1e-3，以及 toi/gated/compensated 的 1e-2、1e-1，各一次 100 帧，共 2100 帧。主实验、参考和消融共 51 个完整运行、5100 帧。
- 默认 Kmin=6 的额外 40 帧轨迹检查：220 次原始 RHS 核验全部一致，86 个活跃预算样本，参考索引和递推通过；49 个完整步长但残差仍大的样本被预算拒绝，54 个纯 TOI 会通过但预算不通过的样本。没有出现“当前残差门控通过、历史预算不通过”的样本。

所有 51 个完整运行均 exit=0，100 帧齐全，无非有限顶点/末速度、Newton 上限命中或图回退。两段图均实际回放。全部预算更新的 `z>=r` 和 `z>=beta` 检查在浮点容差内成立。通过 compensated 分支退出时额外核验了预算阈值。原方向退出路径不承诺该残差界。

另保留 10 倍严格探索：场景 1、3 完成；场景 5 第 50 帧耗时 226.519 秒、3792 次 Newton，第 51 帧再度长时间求解后主动中断。这个不完整运行未计入 51 个完整实验，也未作为完整轨迹精度参考；已留存部分 CSV/状态、日志及 `reference/scene5/EXPLORATION_STATUS.json`。

| 场景 | original 牛顿秒中位数 | 纯 TOI 牛顿秒中位数 | 补偿牛顿秒中位数 | 补偿配对加速比中位数 | original / 纯 TOI / 补偿 最大位置 RMS 差（mm） |
|---|---:|---:|---:|---:|---|
| 1 | 40.069 | 18.221 | 33.079 | 1.211× | 17.108 / 28.057 / 16.175 |
| 3 | 2.862 | 2.850 | 2.843 | 1.000× | 0.025 / 0.023 / 0.024 |
| 5 | 20.634 | 15.475 | 21.635 | 0.925× | 8.489 / 18.444 / 9.316 |

误差是相对完整 2 倍严格参考的全部顶点等权逐帧 RMS，在三次主运行中取最大值。更严格参考不是精确物理解。original 三次重复最大位置 RMS 波动分别为 3.155、0.012822、6.337 mm，不能把很小的误差差异解读为可靠的优势。

世界速度误差从相邻接受位置差 / dt 计算，因为原共享速度缓冲将 ABD 顶点置零，真正 ABD 速度在 q_v。位置映射 J 固定，因此该度量同时适用于 ABD/FEM；没有把 ABD 的速度误差算成零。

| 场景 | original 最大世界速度 RMS（m/s） | 纯 TOI | 补偿 |
|---|---:|---:|---:|
| 1 | 0.136664 | 0.280199 | 0.158522 |
| 3 | 0.000383 | 0.000350 | 0.000368 |
| 5 | 0.132932 | 0.155918 | 0.201146 |

在默认阈值下，补偿保留更多 Newton 工作量，位置轨迹比纯 TOI 接近参考，但速度误差不总是更小，场景 5 也没有速度收益。当前残差门控仅做单次消融，默认索引审计未观测到历史预算相对门控的额外拒绝。**本次不能认定历史补偿稳定优于当前残差门控，也不能宣称普遍提速或更高精度。**

## 几何安全结果

原 GPU 相交查询在每一完整运行的每一帧均返回无相交。静态固定 FEM 顶点漂移均为零（场景 3 有 2 个，场景 5 有 130 个）。

| 场景 | original 单帧最多翻转四面体 | 纯 TOI | 补偿 |
|---|---|---|---|
| 1 | 3 / 2 / 3 | 3 / 1 / 3 | 3 / 4 / 3 |
| 3 | 无四面体 | 无四面体 | 无四面体 |
| 5 | 0 / 0 / 0 | 0 / 0 / 0 | 0 / 0 / 0 |

翻转按当前有向体积相对初态体积的符号改变检查，初态没有被剔除的退化四面体。场景 1 最小体积比明显为负，不能按舍入误差忽略。原规则也有翻转，但这不等于补偿版本已证明安全；补偿第二次出现单帧 4 个翻转。源版本 `InjectiveStepSize` 调用已被注释，本次没有增加新的防翻转数学约束。

**运行与预算核验通过，不代表全部几何安全检查通过。** 累计残差预算只控制附加退出，不能据其标量界保证无翻转、无位置误差或时间积分精度。
