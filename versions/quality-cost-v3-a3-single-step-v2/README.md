# quality-cost-v3 A3 paired single-step binary

This local snapshot is the exact executable and runtime DLL set used for the
validated 336-run A3 matrix. It includes trace-independent diagnostic budgets
and batch checkpoint loading support without changing the solver mathematics.

Binary files are retained locally and ignored by Git. `MANIFEST.json` records
their SHA-256 hashes, the implementation/results commits, and the evidence
manifest location.
