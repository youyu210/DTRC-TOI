# quality-cost-v3 A1 diagnostics

This local binary snapshot corresponds to tag
`quality-cost-v3-a1-diagnostics` and the validated A1 table frame-23
dual-tolerance diagnosis. The executable adds opt-in Newton tracing and
diagnostic budgets; the normal trace-off solver path remains unchanged.

Git. `MANIFEST.json` records their SHA-256 hashes and links to the committed
experiment evidence.
